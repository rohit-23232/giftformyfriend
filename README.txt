CLOSEST FRIEND ❤️ MULTI-PAGE WEBSITE

Files:
- index.html
- about.html
- memories.html
- letter.html
- gallery.html
- final.html
- style.css
- script.js

How to run:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Use English / हिन्दी in the top navigation.
4. The selected language is remembered between pages.

To add real photos:
Replace any .photo div in gallery.html with:
<img src="your-photo.jpg" alt="Our memory">

The site uses Google Fonts via CSS. If offline, it still works using fallback fonts.
